## 1. Брэндийн мөн чанар

**Travel AI** нь Монголын аялал жуулчлалын компанид өдөр тутмын ажлаа удирдаж, хиймэл оюуны тусламжтайгаар шийдвэр гаргахад тусалдаг.

| Бид | Бид биш |
|---|---|
| Тайван, итгэлтэй | Чимэг ихтэй, шуугиантай |
| Тоо, баримт тодорхой | Ойлгомжгүй, техникийн үгтэй |
| Монгол хэлээр энгийн | Англи хэлний холимогтой |
| Байгаль, аялал (ногоон) | Корпорацийн хүйтэн (цэнхэр, саарал) |

**Нэг өгүүлбэрээр:** *Аяллын бизнесийн тооцоог тайван, ойлгомжтой харуулж, AI-ийн зөвлөгөөг тод онцолдог.*

### 3.2 Өнгөний утга: юу юуг илэрхийлдэг вэ

- 🟢 **Ногоон** = систем, тогтвортой байдал, амжилт. Хуудасны 80% нь ногоон ба саармаг.
- 🟠 **Улбар шар** = **үйлдэл ба AI.** "+ Нэмэх", "Таамаглах", ML тэмдэг, таамаглалын тоо, анхаарал татах зүйл. Хуудсанд цөөн байх тусам илүү үр дүнтэй (10%-иас ихгүй).
- 🔴 **Улаан** = зөвхөн устгах ба алдаа.

|---|---|---|---|
| `--fs-3xl` | 40px | 700 | AI таамаглалын гол тоо |

- Гарчиг үргэлж `--green-900`, тод.

- Тоог хүснэгтэд баруун тийш тэгшилнэ (`td.num`).
- ❌ БҮХ ҮСГИЙГ ТОМООР бичихгүй (цэсний бүлгийн нэрээс бусад).

## 5. Зай, булан, сүүдэр

**Зай: 4-ийн алхам.** `4 · 8 · 12 · 16 · 20 · 24 · 28 · 32` (`--s-1` … `--s-8`)

| Хаана | Зай |
|---|---|
| Хуудасны дотор зай | 24px дээр/доор, 28px хажуу |
| Карт хоорондын зай | 14px |
| Панелийн дотор зай | 16px |
| Формын талбар хооронд | 10px |

**Булан:** товч/input `6px` · карт/панел `10px` · нэвтрэх карт `12px` · pill/лого бүтэн дугуй.

**Сүүдэр:** зөвхөн **хөвөгч** зүйлд (toast, нэвтрэх карт). Карт, панелд сүүдэр биш **1px хүрээ** (`--line`).

## 6. Бүрэлдэхүүн хэсгүүд

### 6.1 Товч

| Төрөл | Класс | Хэзээ |
|---|---|---|
| Үндсэн | `.btn.btn--primary` | Хуудсанд **нэг л** гол үйлдэл: "+ Нэмэх", "Таамаглах" |
| Амжилт | `.btn.btn--success` | Форм илгээх: "Хадгалах", "Нэмэх", "Нэвтрэх" |
| Ghost | `.btn.btn--ghost` | "Болих" |
| Аюултай | `.btn.btn--danger` | Устгахыг баталгаажуулах цонхонд |
| Мөрийн | `.btn-sm--edit / --delete / --confirm / --cancel` | Хүснэгтийн мөр бүрт: Засах, Устгах, Батлах, Цуцлах |

```html
<button class="btn btn--primary">+ Нэмэх</button>
<button class="btn btn--success">Хадгалах</button>
<button class="btn btn--ghost">Болих</button>
```

### 6.2 Төлөвийн pill

| Төлөв | Класс | Текст |
|---|---|---|
| pending | `.pill.pill--pending` | Хүлээгдэж буй |
| confirmed | `.pill.pill--confirmed` | Батлагдсан |
| cancelled | `.pill.pill--cancelled` | Цуцлагдсан |

### 6.3 KPI карт

```html
<div class="kpi-grid">
  <div class="kpi"><div class="kpi__label">Нийт аялал</div><div class="kpi__value">150</div></div>
</div>
```
Хяналтын самбарын дээд хэсэгт 4 ширхэг. Утас дээр 2 багана.

### 6.4 AI / ML

AI-тай холбоотой бүхэн **улбар шар**-аар ялгарна:
- Гарчгийн хажууд `.tag` → <kbd>ML</kbd>
- Таамаглалын тоо хүснэгтэд `td.ai`, ганцаараа `.ai-number` (40px)
- Таамаглалыг үргэлж **бодит утгын хажууд** харуулна (Бодит | Таамаглал).
- Аравтын нэг орон: `12.5`, сөрөг бол `0`.

### 6.5 Хүснэгт
Толгой нь `--green-50` дэвсгэртэй, мөр бүр доороо 1px зураастай. Шинэ мөр **хамгийн дээр**. Үйлдлийн товчнууд хамгийн баруун баганад.

### 6.6 Форм
Label дээр, input доор (`.field`). Заавал бөглөх талбарт `*`. Формын доор: `[Хадгалах] [Болих]`.

### 6.7 Мэдэгдэл (toast)
Баруун доод буланд. Амжилт ногоон, 2.5 секунд. Алдаа улаан, 5 секунд.

## 9. Шинэ вэб эхлүүлэх заавар

1. Энэ хавтсаас `brand.css`-ийг шинэ төсөл рүү хуулна.
2. HTML-д холбоно:
   ```html
   <link rel="stylesheet" href="brand.css">
   <link rel="stylesheet" href="style.css">  <!-- зөвхөн тухайн вэбийн онцлог -->
   ```
3. `style.css`-д **шинэ өнгө бүү зохио.** `var(--green-700)` гэх мэт token хэрэглэ.
4. Шинэ бүрэлдэхүүн хэрэгтэй бол эхлээд энд (`brand.css` + `README.md`) нэмээд, дараа нь хэрэглэ.
5. `index.html`-ийг нээж харьцуулна: шинэ хуудас ижил гэр бүлийнх шиг харагдаж байна уу?

**AI хэрэгсэлд (Claude Code, Copilot) өгөх prompt-ын эхлэл:**
> *"00-brand-book/README.md ба brand.css-ийн дүрмийг баримтал. Шинэ өнгө, фонт бүү нэм; зөвхөн тэнд байгаа token, класс хэрэглэ."*
